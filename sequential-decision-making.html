Branch 02

Sequential decision-making under partial feedback.

This branch follows bandits, exploration, exploitation, regret, and offline evaluation: situations where learning and acting are tangled together.

bandits logged feedback policy evaluation
Core question

How can a system learn when it only observes feedback from actions it chose?

I am drawn to this area because the evaluation problem is already part of the decision problem. Logged data is biased by past choices, exploration has a cost, and a policy can look good for reasons that disappear online.

Question

Can offline metrics rank online behaviour?

IPS, confidence intervals, and effective sample size can help, but the harder question is when they fail to preserve the ordering we care about.

Method lens

Exploration has to be measured.

I care about the difference between genuine exploration and systems that only appear adaptive because the possible action set has already been narrowed.

Related work

Bandits as a bridge.

My offline bandit evaluation project and current LLM exploration preparation both use bandits as a language for studying adaptive choice.
