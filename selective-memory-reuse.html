Research note

Evaluating Selective Memory Reuse in LLM Agents

A retrieved case can help an agent finish a task, distract it, or offer no advantage. I tested when to reuse that experience, when to abstain, and whether runtime evidence can support recovery after harmful reuse.

View public project
Question

Can an agent tell when a retrieved case is useful before acting on it?

A relevant case is not necessarily a useful one. The decision is whether using a particular memory improves the outcome for the same target compared with using no memory. A useful selective policy must also beat strong fixed choices, including always using the best retrieved case and never using memory.

Candidate selection

Retrieve, rerank, or abstain

I separated retrieval from the decision to use a case, then compared no history, always-use, and selective policies on frozen target and candidate assignments.

Evaluation

Compare policies on paired tasks

I compared policies on paired tasks in AppWorld and ScienceWorld, using frozen assignments and group-aware analysis for AppWorld and strict process checks for ScienceWorld.

Runtime recovery

Suppress harmful reuse and replan

Later tests asked whether a timely failure signal and a feasible recovery action could improve a memory-conditioned run after execution had begun.

Selected evidence

Memory provided real benefits in some settings. The harder claim was that an adaptive decision rule could consistently beat the strongest simple policy on independent tasks. The results below come from different experiments and use different outcome measures.

AppWorld · 168 targets / 56 groups

Reranking helped; selective abstention fell short.

Formal success rates were 69.64% with no history, 75.60% with always-reranked memory, and 73.21% with selective reranking. The selector did not beat the stronger fixed memory policy.

ScienceWorld · 12 targets

Raw history improved strict process success.

Under a shared executor, no history succeeded on 5/12 tasks and raw history on 9/12. Always using raw history already matched the observed hindsight oracle, leaving no demonstrated advantage for a selector in this panel.

Controlled recovery · synthetic panels

Recovery worked when the signal was clean.

An adaptive policy beat fixed arms in a constructed procedural test. Across six fresh synthetic panels its gain over the initial policy was about 0.086, below the preset 0.10 promotion margin, so the broader result remained inconclusive.

Real-agent pilot · three ScienceWorld targets

No stable controller advantage appeared.

The small LLM pilot did not show an adaptive gain over fixed policies. Two utility outputs were malformed, which further limits what this implementation can establish.

Result

Useful memory is easier to demonstrate than reliable selection.

Retrieved experience helped when task and execution conditions aligned, and recovery was possible under controlled signals. Yet relevance did not reliably predict a case's incremental value, and the tested selective policies did not consistently outperform strong fixed baselines on independent tasks. The conclusion is limited to these experiments; it does not rule out other memory-selection methods.

The public project includes the research overview, evidence provenance, limitations, and a small protocol demonstration. It is a curated showcase rather than a full reproduction package for the benchmark experiments.
