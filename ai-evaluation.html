Branch 03

Evaluation for AI systems that make decisions.

I am interested in LLMs less as static text generators and more as systems that choose, adapt, retrieve, generate candidates, and act under an evaluation protocol.

LLM policies adaptive systems trustworthy tests
Core question

What does it mean for an adaptive AI system to perform well?

A single benchmark score often hides the decision process. This branch asks how to evaluate systems whose behaviour depends on prompts, candidate generation, memory, feedback, and the structure of the task they are given.

Question

Is performance or action-space reduction doing the work?

If a pipeline first generates a small candidate set and then chooses, I want to know whether the model learned a better policy or inherited an easier problem.

Method lens

Evaluation should expose the mechanism.

Useful experiments should separate retrieval, candidate generation, selection, exploration, and feedback rather than compressing everything into one score.

Related work

LLMs meet sequential decisions.

My current preparation connects LLM decision-making with in-context RL, bandits, offline bias, and evaluation protocols for adaptive systems.
