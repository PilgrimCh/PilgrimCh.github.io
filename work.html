Offline bandit evaluation IPS vs regret

IPS vs Regret in Offline Bandit Evaluation

07/2025 - 09/2025

Inverse propensity scoring is tested as an offline proxy for cumulative regret in logged bandit data. The comparison uses Explore-Then-Commit, UCB, and Thompson Sampling on Yelp and MovieLens-style logs, with regret curves, IPS estimates, bootstrap confidence intervals, effective sample size, and agreement tests between online and offline rankings.

IPS is useful as an offline proxy, but it does not reliably replace regret. Confidence intervals often overlap, short-horizon and small-dataset rankings can disagree, and ESS helps explain reliability without removing the underlying metric gap.

Hydrological time series Daily Hydropeaking Index

Hydropeaking Data Cleaning and Daily Hydropeaking Index Definition

06/2024 - 09/2024

Hydropeaking describes rapid flow fluctuations associated with hydropower operation. Hydrological and water-quality records are cleaned and aligned, station and dam fields are checked, and a Daily Hydropeaking Index is defined from weekly hydropeaking ideas.

The index work turns messy monitoring tables into standardized time-series records and converts a literature-based periodicity idea into a computable daily metric.

Pendulum: 10/2025 - 01/2026 Thermostat: 01/2026 - 04/2026
